# AGENTS.md

This repository mirrors the curated Awesome-Selfhosted list. New software additions and edits to the catalog must be submitted to [awesome-selfhosted-data](https://github.com/awesome-selfhosted/awesome-selfhosted-data), not here.

## Editing guidelines

- Keep entries in the existing section order and, where practical, in alphabetical order within each section.
- Follow the existing README formatting for software entries:
  - ``- [Project Name](https://example.com) - Short description. ([Source Code](https://github.com/example/project)) `License` `Tech` ``
  - Use the same punctuation and spacing style as nearby entries.
  - When relevant, include `([Demo](...))` or `([Clients](...))` links in the same style as existing entries.
  - Preserve the `⚠` marker for projects that are marked as unmaintained or otherwise flagged.
- Prefer adding entries that are clearly free/open source, self-hostable, and have a visible source repository and license.
- Do not invent URLs, licenses, or project descriptions; use official project information when possible.
- Do not add new top-level sections unless the change truly requires it.
- Keep descriptions concise and factual; avoid marketing language.

## Scope

- New software additions and catalog edits go to [awesome-selfhosted-data](https://github.com/awesome-selfhosted/awesome-selfhosted-data).
- `non-free.md` is only for non-free software and should be handled carefully.
